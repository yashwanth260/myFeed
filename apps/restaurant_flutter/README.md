# Feedo Restaurant Partner — Flutter Mobile Application

A native Flutter mobile application designed specifically for restaurant managers and kitchen chefs.

## 📱 Features
- **Live Kitchen Order Queue:** Real-time incoming, preparing, and ready-for-pickup tabs.
- **Store Availability Control:** Instant toggle to mark kitchen online/offline.
- **Menu Stock Management:** One-tap toggle for item availability & 86ing out-of-stock dishes.
- **Settlements & Payouts:** Real-time gross order value, platform commissions, and bank transfer logs.
- **REST & Socket Integration:** Direct integration with CraveCart / Feedo Unified Backend (`/api/v1`).

## 🚀 How to Run
```bash
# 1. Navigate to directory
cd apps/restaurant_flutter

# 2. Get dependencies
flutter pub get

# 3. Run on connected Android / iOS device or emulator
flutter run

# 4. Build Release APK
flutter build apk --release
```
