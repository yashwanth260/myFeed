# Feedo Delivery Partner — Flutter Mobile Application

A native Flutter mobile application tailored for delivery partners, fleet couriers, and rider fleets.

## 📱 Features
- **Live Duty Toggle:** Instant Online / Offline switch with GPS broadcasting.
- **Dispatch Offer Screen:** Floating card with restaurant pickup, customer drop, distance, and earnings payout.
- **Trip Navigation & OTP:** Step-by-step route to kitchen, package collection, and customer OTP delivery confirmation.
- **Wallet & Weekly Settlements:** Real-time earnings tally, tip breakdown, and instant UPI cashout.
- **Safety SOS & Support:** Emergency contact triggers and 24x7 support desk.
- **Backend Sync:** Communicates directly with CraveCart / Feedo REST API (`/api/v1`).

## 🚀 How to Run
```bash
# 1. Navigate to directory
cd apps/delivery_flutter

# 2. Get dependencies
flutter pub get

# 3. Run on connected Android / iOS device or emulator
flutter run

# 4. Build Release APK
flutter build apk --release
```
